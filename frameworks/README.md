# 框架与库

前端开发中常用的框架和库，它们可以提高开发效率，简化代码结构，提供更好的性能和用户体验。

## 分类内容

### React
- 核心概念与 Hooks
- 进阶特性与生态
- Next.js 框架
- 最佳实践

### Vue
- Vue 2 与 Vue 3
- 核心概念与 Composition API
- Nuxt.js 框架
- 最佳实践

### Angular
- 核心概念与架构
- 进阶特性与工具链
- 最佳实践

### Svelte
- 核心概念与响应式系统
- SvelteKit 框架
- 最佳实践

### 其他流行库
- jQuery
- Lodash/Underscore
- 日期处理库
- HTTP 客户端
- 图表库
- 3D 库

## 学习路径

1. 选择一个主流框架（React/Vue/Angular/Svelte）深入学习
2. 了解框架的核心概念和生态系统
3. 学习相关的构建工具和状态管理方案
4. 实践项目开发，积累经验
