# 浏览器与网络

了解浏览器的工作原理和网络协议，对于前端开发至关重要，可以帮助开发者更好地理解和优化网页性能。

- 渲染流程
- JavaScript 引擎
- 事件循环
- 存储机制

### HTTP 协议
- HTTP 基础
- HTTP/1.1 vs HTTP/2 vs HTTP/3
- HTTPS
- RESTful API
- GraphQL
- WebSocket

### Web API
- DOM API
- BOM API
- Fetch API
- Web Storage API
- IndexedDB
- Web Audio API
- Web Speech API
- WebXR API

### 浏览器兼容性
- 兼容性处理策略
- Polyfill
- 降级方案
- 浏览器市场份额

## 学习路径

1. 学习浏览器的基本架构和渲染流程
2. 深入了解 HTTP 协议和网络通信
3. 掌握常用的 Web API
4. 学习浏览器兼容性处理方法
