# 基础核心

前端开发的基础核心知识，是构建任何前端应用的基石。本分类包含 HTML、CSS、JavaScript 和 TypeScript 等核心技术。

## 分类内容

### HTML
- 基本概念与文档结构
- 常用标签与语义化
- HTML5 新特性
- 最佳实践

### CSS
- 语法与选择器
- 盒模型与布局
- 样式与动画
- CSS 预处理器与架构
- 最佳实践

### JavaScript
- 语言基础与高级特性
- 异步编程与事件循环
- DOM/BOM 操作
- 模块化与设计模式
- 最佳实践

### TypeScript
- 基础语法与类型系统
- 高级特性与编译配置
- 最佳实践

## 学习路径

1. 从 HTML 开始，了解网页的基本结构
2. 学习 CSS，掌握网页样式设计
3. 学习 JavaScript，实现交互功能
4. 学习 TypeScript，提升代码质量和可维护性
