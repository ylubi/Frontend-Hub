# 安全

Web 安全是前端开发中不可忽视的重要领域，了解常见的安全威胁和防护措施，可以保护用户数据和系统安全。

## 分类内容

### Web 安全基础
- 同源策略
- CORS
- CSP

### XSS 防护
- 反射型 XSS
- 存储型 XSS
- DOM 型 XSS
- 防护措施

### CSRF 防护
- 攻击原理
- 防护措施

### 数据安全
- 数据加密
- 敏感数据处理
- 隐私保护

### 身份验证与授权
- Cookie/Session
- JWT
- OAuth 2.0
- OpenID Connect
- 生物识别认证

## 学习路径

1. 了解 Web 安全的基本概念和常见威胁
2. 学习各种安全防护措施的原理和实现方法
3. 掌握身份验证和授权的最佳实践
4. 了解数据安全和隐私保护的相关法规
