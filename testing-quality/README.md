# 测试与质量保障

测试与质量保障是前端开发流程中的重要环节，可以确保代码质量、减少bug、提高软件的可靠性和可维护性。

## 分类内容

### 单元测试
- 测试框架（Jest、Mocha、Vitest）
- 断言库
- 测试覆盖率

### 集成测试
- React Testing Library
- Vue Test Utils
- Cypress Component Testing

### E2E 测试
- Cypress
- Playwright
- Puppeteer

### 测试工具
- Testing Library
- Sinon
- Mock Service Worker

### 代码质量
- 代码审查
- 静态分析
- 复杂度分析

## 学习路径

1. 学习单元测试的基本概念和框架
2. 掌握集成测试的实现方法
3. 了解 E2E 测试的流程和工具
4. 建立代码质量保障体系
