# 跨端开发

跨端开发是指使用一套代码或相似的开发模式，同时开发出能够在不同平台上运行的应用，提高开发效率和代码复用率。

## 分类内容

### 移动端开发
- 响应式设计
- 移动端适配
- PWA
- TWA

### 桌面端开发
- Electron
- NW.js
- Tauri

### 小程序开发
- 微信小程序
- 支付宝小程序
- 百度小程序
- 跨平台小程序框架（Taro、Uni-app）

### WebAssembly
- 基本概念
- 使用场景
- 编译工具（Emscripten、Rust + Wasm）

## 学习路径

1. 了解不同跨端开发技术的优缺点
2. 选择适合项目需求的跨端方案
3. 学习相关框架和工具
4. 实践跨端应用开发
