# 工程化

前端工程化是指将软件工程的原则和方法应用于前端开发，提高开发效率、代码质量和可维护性。

## 分类内容

### 构建工具
- Webpack
- Vite
- Rollup
- Parcel
- Esbuild

### 包管理
- npm
- Yarn
- pnpm

### 代码规范
- ESLint
- Prettier
- Stylelint
- Husky
- Lint-staged

### CI/CD
- GitHub Actions
- GitLab CI
- Jenkins
- CircleCI

### 开发环境
- VS Code 配置
- Chrome DevTools
- 调试技巧
- 热更新
- Mock 数据

## 学习路径

1. 学习常用的构建工具和包管理工具
2. 建立代码规范和质量保障体系
3. 配置 CI/CD 流程，实现自动化部署
4. 优化开发环境，提高开发效率
